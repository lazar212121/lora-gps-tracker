ESP32-C3 + LoRa XL1278 + GPS Uputstvo

1. Šema Povezivanja (Pinout Wiring)

A. TRANSMITER (ESP32-C3 + XL1278 + NEO-6M)
  • LoRa XL1278 (SPI):
  • VCC ➔ 3.3V | GND ➔ GND
  • SCK ➔ GPIO 4 | MISO ➔ GPIO 5
  • MOSI ➔ GPIO 6 | NSS (CS) ➔ GPIO 7
  • RST ➔ GPIO 3 | DIO0 ➔ GPIO 2
  • NEO-6M GPS (UART):
  • VCC ➔ 3.3V / 5V | GND ➔ GND
  • TX ➔ GPIO 20 (ESP RX)
  • RX ➔ GPIO 21 (ESP TX)
B. PRIJEMNIK / RESIVER (ESP32-C3 + XL1278)
  • LoRa XL1278 (SPI):
  • VCC ➔ 3.3V | GND ➔ GND
  • SCK ➔ GPIO 4 | MISO ➔ GPIO 5
  • MOSI ➔ GPIO 6 | NSS (CS) ➔ GPIO 7
  • RST ➔ GPIO 3 | DIO0 ➔ GPIO 2
  • Komunikacija:
  • ESP32-C3 emituje BLE (Bluetooth Low Energy) podatke ka ovoj aplikaciji.

2. Kod za ESP32-C3 Prijemnik (Arduino IDE)

Prijemnik prima LoRa paket od predajnika u formatu ID,LAT,LNG,SPEED (npr. TRK-01,43.6241,21.0084,14.5) i prosleđuje ga preko Bluetooth Serial / BLE konekcije na vaš telefon. 

#include <SPI.h>
#include <LoRa.h>
#include <BLEDevice.h>
#include <BLEServer.h>
#include <BLEUtils.h>
#include <BLE2902.h>

#define SCK 4
#define MISO 5
#define MOSI 6
#define SS 7
#define RST 3
#define DI0 2

BLECharacteristic *pCharacteristic;
bool deviceConnected = false;

#define SERVICE_UUID        "4fafc201-1fb5-459e-8fcc-c5c9c331914b"
#define CHARACTERISTIC_UUID "beb5483e-36e1-4688-b7f5-ea07361b26a8"

class MyServerCallbacks: public BLEServerCallbacks {
    void onConnect(BLEServer* pServer) { deviceConnected = true; };
    void onDisconnect(BLEServer* pServer) { deviceConnected = false; BLEDevice::startAdvertising(); }
};

void setup() {
  Serial.begin(115200);
  
  // LoRa Init
  SPI.begin(SCK, MISO, MOSI, SS);
  LoRa.setPins(SS, RST, DI0);
  if (!LoRa.begin(433E6)) { // ili 868E6 u zavisnosti od XL1278 verzije
    Serial.println("LoRa greška!");
    while (1);
  }

  // BLE Init
  BLEDevice::init("LoRa_GPS_Receiver");
  BLEServer *pServer = BLEDevice::createServer();
  pServer->setCallbacks(new MyServerCallbacks());
  BLEService *pService = pServer->createService(SERVICE_UUID);
  pCharacteristic = pService->createCharacteristic(
                      CHARACTERISTIC_UUID,
                      BLECharacteristic::PROPERTY_READ   |
                      BLECharacteristic::PROPERTY_NOTIFY
                    );
  pCharacteristic->addDescriptor(new BLE2902());
  pService->start();
  BLEDevice::startAdvertising();
}

void loop() {
  int packetSize = LoRa.parsePacket();
  if (packetSize) {
    String incoming = "";
    while (LoRa.available()) {
      incoming += (char)LoRa.read();
    }
    Serial.println("LoRa Primljeno: " + incoming);
    if (deviceConnected) {
      pCharacteristic->setValue(incoming.c_str());
      pCharacteristic->notify();
    }
  }
}
